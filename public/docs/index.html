VOICENOTE / MCP

AI integration

Connect your notes to your AI assistant.

Voicenote supports long recordings, timestamped memos and bookmarks, on-device Whisper transcription, AI summaries, keywords and todos, cloud sync, M4A export, and file-upload transcription.

1. Create a token

In the app, open Settings → AI integration → Create token. Copy the personal access token: it is shown only once. You can revoke it at any time. Replace vn_... in the examples with your token.

2. Connection

Public documentation needs no login. MCP uses Streamable HTTP (stateless JSON), protocol 2025-06-18. Send Authorization: Bearer vn_... on every request. No session ID is required.

https://voicenote-ten-alpha.vercel.app/api/mcp
Authorization: Bearer vn_...

3. Read-only tools

list_notes

{query?: string, limit?: number}

List notes, optionally filtered by query. Limit defaults to 20; maximum 100.

get_note

{id: string, include_transcript?: boolean}

Get title, date, duration, summary with timestamps, keywords, todos, memos, and transcript lines formatted as [mm:ss] text. include_transcript defaults to true.

search_transcripts

{query: string, limit?: number}

Search transcript text. Results contain noteId, noteTitle, startMs, text. Limit defaults to 20; maximum 100.

get_summary

{id: string}

Get a note’s summary.

Use list_notes to find a note ID for get_note or get_summary. These tools cannot change notes or generate summaries.

4. Claude Desktop / Claude Code

Claude Desktop: configure a remote Streamable HTTP connection with the endpoint and Authorization header. Custom header support depends on your client version. If unavailable, use Claude Code. The following command configures Claude Code only.

claude mcp add --transport http voicenote https://voicenote-ten-alpha.vercel.app/api/mcp --header "Authorization: Bearer vn_..."

5. Cursor

Merge this configuration into Cursor’s mcp.json.

{
  "mcpServers": {
    "voicenote": {
      "url": "https://voicenote-ten-alpha.vercel.app/api/mcp",
      "headers": {
        "Authorization": "Bearer vn_..."
      }
    }
  }
}

6. curl

Set VOICENOTE_TOKEN securely in your local shell. Initialize, send the initialized notification, then call a tool.

curl https://voicenote-ten-alpha.vercel.app/api/mcp \
  -H "Authorization: Bearer $VOICENOTE_TOKEN" \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json, text/event-stream' \
  --data '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-06-18","capabilities":{},"clientInfo":{"name":"voicenote-example","version":"1.0.0"}}}'
curl https://voicenote-ten-alpha.vercel.app/api/mcp \
  -H "Authorization: Bearer $VOICENOTE_TOKEN" \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json, text/event-stream' \
  -H 'MCP-Protocol-Version: 2025-06-18' \
  --data '{"jsonrpc":"2.0","method":"notifications/initialized"}'
curl https://voicenote-ten-alpha.vercel.app/api/mcp \
  -H "Authorization: Bearer $VOICENOTE_TOKEN" \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json, text/event-stream' \
  -H 'MCP-Protocol-Version: 2025-06-18' \
  --data '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"list_notes","arguments":{"limit":20}}}'

7. Privacy

Your token reads all of your own notes. Connect only trusted clients and keep the token private. Revoke it anytime in the app; previously copied data remains with the client. Recording audio is not exposed via MCP.
