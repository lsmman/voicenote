VOICENOTE / MCP

AI 集成指南

将语音笔记连接到 AI 助手。

Voicenote 支持长时间录音、带时间戳的备忘和书签、设备端 Whisper 转写、AI 摘要、关键词和待办事项、云同步、M4A 导出以及上传文件转写。

1. 创建令牌

在应用中打开 设置 → AI 集成 → 创建令牌（Create token）。个人访问令牌仅显示一次，请妥善保存。您可以随时撤销。将示例中的 vn_... 替换为自己的令牌。

2. 连接信息

本文档公开，无需登录。MCP 使用 Streamable HTTP（无状态 JSON），协议版本为 2025-06-18。每个请求都需发送 Authorization: Bearer vn_... 请求头。无需会话 ID。

https://voicenote-ten-alpha.vercel.app/api/mcp
Authorization: Bearer vn_...

3. 只读工具

list_notes

{query?: string, limit?: number}

列出笔记，可选 query 筛选。limit 默认为 20，最大为 100。

get_note

{id: string, include_transcript?: boolean}

获取标题、日期、时长、带时间戳的摘要、关键词、待办事项、备忘以及 [mm:ss] text 格式的转写行。include_transcript 默认为 true。

search_transcripts

{query: string, limit?: number}

搜索转写文本，query 必填。结果包含 noteId、noteTitle、startMs、text。limit 默认为 20，最大为 100。

get_summary

{id: string}

获取指定笔记的摘要。

先使用 list_notes 获取笔记 ID，再调用 get_note 或 get_summary。这些工具不能修改笔记或生成摘要。

4. Claude Desktop / Claude Code

在 Claude Desktop 中使用下方端点和 Authorization 请求头配置远程 Streamable HTTP 连接。自定义请求头支持取决于客户端版本；若不支持，请使用 Claude Code。以下命令仅配置 Claude Code。

claude mcp add --transport http voicenote https://voicenote-ten-alpha.vercel.app/api/mcp --header "Authorization: Bearer vn_..."

5. Cursor

将以下配置合并到 Cursor 的 mcp.json 中。

{
  "mcpServers": {
    "voicenote": {
      "url": "https://voicenote-ten-alpha.vercel.app/api/mcp",
      "headers": {
        "Authorization": "Bearer vn_..."
      }
    }
  }
}

6. curl

在本地 shell 中安全地设置 VOICENOTE_TOKEN。依次发送初始化请求、初始化完成通知和工具调用。

curl https://voicenote-ten-alpha.vercel.app/api/mcp \
  -H "Authorization: Bearer $VOICENOTE_TOKEN" \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json, text/event-stream' \
  --data '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-06-18","capabilities":{},"clientInfo":{"name":"voicenote-example","version":"1.0.0"}}}'
curl https://voicenote-ten-alpha.vercel.app/api/mcp \
  -H "Authorization: Bearer $VOICENOTE_TOKEN" \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json, text/event-stream' \
  -H 'MCP-Protocol-Version: 2025-06-18' \
  --data '{"jsonrpc":"2.0","method":"notifications/initialized"}'
curl https://voicenote-ten-alpha.vercel.app/api/mcp \
  -H "Authorization: Bearer $VOICENOTE_TOKEN" \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json, text/event-stream' \
  -H 'MCP-Protocol-Version: 2025-06-18' \
  --data '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"list_notes","arguments":{"limit":20}}}'

7. 隐私与权限

令牌授予对您自己所有笔记的读取权限。仅连接可信客户端，切勿公开令牌。可随时在应用中撤销，但已复制到客户端的数据不会被删除。MCP 不提供录音音频。
