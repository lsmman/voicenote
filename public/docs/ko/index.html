VOICENOTE / MCP

AI 연동 안내

음성 노트를 AI 도우미와 연결하세요.

Voicenote는 장시간 녹음, 타임스탬프 메모와 북마크, 기기 내 Whisper 전사, AI 요약과 키워드·할 일, 클라우드 동기화, M4A 내보내기, 파일 업로드 전사를 지원합니다.

1. 토큰 만들기

앱의 설정 → AI 연동 → 토큰 만들기(Create token)에서 개인 액세스 토큰을 생성하세요. 토큰은 한 번만 표시되므로 안전하게 보관하세요. 언제든 폐기할 수 있습니다. 예시의 vn_...를 본인 토큰으로 바꾸세요.

2. 연결 정보

이 문서는 로그인 없이 볼 수 있습니다. MCP는 Streamable HTTP(무상태 JSON), 프로토콜 2025-06-18을 사용합니다. 모든 요청에 Authorization: Bearer vn_... 헤더를 보내세요. 세션 ID는 필요하지 않습니다.

https://voicenote-ten-alpha.vercel.app/api/mcp
Authorization: Bearer vn_...

3. 읽기 전용 도구

list_notes

{query?: string, limit?: number}

노트 목록을 조회합니다. query는 선택 항목입니다. limit 기본값은 20, 최댓값은 100입니다.

get_note

{id: string, include_transcript?: boolean}

제목, 날짜, 길이, 타임스탬프가 있는 요약, 키워드, 할 일, 메모와 [mm:ss] text 형식의 전사 줄을 조회합니다. include_transcript 기본값은 true입니다.

search_transcripts

{query: string, limit?: number}

전사를 검색합니다. query는 필수입니다. 결과: noteId, noteTitle, startMs, text. limit 기본값은 20, 최댓값은 100입니다.

get_summary

{id: string}

지정한 노트의 요약을 조회합니다.

list_notes로 노트 ID를 확인한 뒤 get_note 또는 get_summary에 사용하세요. 이 도구들은 노트를 변경하거나 요약을 생성하지 않습니다.

4. Claude Desktop / Claude Code

Claude Desktop에서는 아래 주소와 Authorization 헤더로 원격 Streamable HTTP 연결을 설정하세요. 사용자 지정 헤더 지원은 클라이언트 버전에 따라 다릅니다. 지원하지 않으면 Claude Code를 사용하세요. 다음 명령은 Claude Code에만 적용됩니다.

claude mcp add --transport http voicenote https://voicenote-ten-alpha.vercel.app/api/mcp --header "Authorization: Bearer vn_..."

5. Cursor

Cursor의 mcp.json에 아래 설정을 병합하세요.

{
  "mcpServers": {
    "voicenote": {
      "url": "https://voicenote-ten-alpha.vercel.app/api/mcp",
      "headers": {
        "Authorization": "Bearer vn_..."
      }
    }
  }
}

6. curl

로컬 셸에 VOICENOTE_TOKEN을 안전하게 설정하세요. 초기화 요청, 초기화 완료 알림, 도구 호출 순서입니다.

curl https://voicenote-ten-alpha.vercel.app/api/mcp \
  -H "Authorization: Bearer $VOICENOTE_TOKEN" \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json, text/event-stream' \
  --data '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-06-18","capabilities":{},"clientInfo":{"name":"voicenote-example","version":"1.0.0"}}}'
curl https://voicenote-ten-alpha.vercel.app/api/mcp \
  -H "Authorization: Bearer $VOICENOTE_TOKEN" \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json, text/event-stream' \
  -H 'MCP-Protocol-Version: 2025-06-18' \
  --data '{"jsonrpc":"2.0","method":"notifications/initialized"}'
curl https://voicenote-ten-alpha.vercel.app/api/mcp \
  -H "Authorization: Bearer $VOICENOTE_TOKEN" \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json, text/event-stream' \
  -H 'MCP-Protocol-Version: 2025-06-18' \
  --data '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"list_notes","arguments":{"limit":20}}}'

7. 개인정보와 접근 권한

토큰은 본인의 모든 노트에 대한 읽기 권한을 부여합니다. 신뢰하는 클라이언트만 연결하고 토큰을 공개하지 마세요. 앱에서 언제든 폐기할 수 있지만 이미 클라이언트에 복사된 데이터는 삭제되지 않습니다. 녹음 오디오는 MCP로 제공되지 않습니다.
