# voicenote — 기획 메모

작성: 2026-10-13

## 출발점

장시간 녹음을 받아 적는 음성 노트 앱을 만들자는 데서 시작. 기능 중
어디까지를 범위로 잡을지 대화로 좁혔다.

## 결정 사항

> 2026-10-13 갱신: 형태·범위·STT 엔진 등은 [설계 문서](superpowers/specs/2026-10-13-voicenote-design.md)로 대체됨.

| 항목 | 결정 |
|---|---|
| 폴더명 | `voicenote` |
| 형태 | 웹앱 (Next.js) |
| 범위 | 녹음 + STT 전사 / 화자 분리 / AI 요약 + 키워드 |
| 노트 편집 UI | 이번 범위에서 빠짐 |

## 범위 상세

**녹음 + STT 전사** — 브라우저에서 녹음하거나 오디오 파일을 올리면 텍스트로
전사한다. 핵심 엔진 부분.

**화자 분리** — 전사문에서 누가 말했는지 구분한다 (speaker diarization).

**AI 요약 + 키워드** — 전사문에서 요약, 할 일, 키워드를 뽑는다.

## 아직 안 정한 것

- STT 엔진 (Whisper / Clova Speech / Deepgram 등)
- 화자 분리를 STT 엔진에 맡길지 별도 파이프라인으로 둘지
- 저장소 (오디오 파일, 전사문, 요약)
- 인증 여부
- 노트 편집 UI를 다음 범위로 넣을지
